## Destination

An implementation-ready specification for a lightweight 3D orbital galaxy surface covering Mino's durable owner-relevant universe: Memory, Responsibilities, Routines, and Conversations. The galaxy is for exploration; Today and Work remain the operational surfaces.

The specification preserves truthful data and existing capabilities while defining stable spatial navigation, guided focus, scalable graph delivery, dependency-free native WebGL2 rendering, and a measurable performance contract.

## Notes

- Planning only until the owner explicitly approves implementation.
- Preserve Mino's light visual system; galaxy depth does not imply glow, neon, fake activity, or decorative particles.
- Preserve graph data, routes, query behavior, and operational surfaces; this effort changes presentation and interaction.
- Desktop dashboard first; mobile galaxy navigation is out of scope because Telegram is the normal phone interface.
- Live baseline checked 2026-08-16: v2.11.0, 888 memory Markdown files, 1,519 Universe nodes, 2,269 edges, and approximately one to two distillation writes every five minutes.

## Decisions so far

- Orbital Galaxy: guided orbit around Mino, progressive cluster-to-node disclosure, hidden edges until focus, and short localized activity trails.
- Navigation and focus: guided orbit with semantic zoom, focused local edges and inspector, deep-linked selection, desktop cluster fallback, and dependency-free native WebGL2.
- Performance: plan for 100k nodes and roughly 1M edges through coarse-first loading, on-demand neighborhoods, dynamic WebGL2 budgets, a 60 FPS target/30 FPS floor, and immediate refinement.
