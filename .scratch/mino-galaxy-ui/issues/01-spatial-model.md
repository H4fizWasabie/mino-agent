# Galaxy spatial model

Status: resolved
Type: grilling

## Question

What orbital regions, anchors, depth cues, and stable placement rules should make Mino's durable owner-relevant universe readable as a 3D galaxy while preserving real topology and community meaning?

## Answer

Choose the **Orbital Galaxy** direction. Mino is the stable owner-world anchor; Memory, Responsibilities, Routines, and Conversations occupy orbital regions around it. Use guided orbit rather than unrestricted camera physics, stable deterministic placement, restrained depth through scale and perspective, and progressive disclosure so clusters and anchors lead at overview while individual nodes appear on zoom or focus. Hide relationship edges by default and reveal them for a selected node or community. Real-time activity is represented by short localized event trails, never perpetual ambient motion.

The prototype decision page is available at `http://127.0.0.1:8790/?variant=orbital`; it uses synthetic data and is not production code.
