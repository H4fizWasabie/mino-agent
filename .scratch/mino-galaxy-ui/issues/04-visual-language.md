# Galaxy visual language

Status: resolved
Type: grilling

## Question

How should orbital depth, communities, node kinds, attention, state, recency, and activity be expressed within Mino's existing light/no-glow visual language without turning the surface into decorative space art?

## Answer

Use scale, perspective, and occlusion for depth; never glow. Give communities
restrained hue families plus orbital regions. Express node kind through color
and shape/outline. Express attention and state through explicit labels/badges
and a bounded accent ring. Keep recency in inspector and timeline metadata.
Activity is limited to short, localized event trails. All status meaning must
remain legible without color or motion.
