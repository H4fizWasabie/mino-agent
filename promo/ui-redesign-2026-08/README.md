# Mino UI redesign visual archive

This directory keeps the PNG source material for the August 2026 Nowfield
redesign and future promotional work.

## Concepts

`concepts/` contains every candidate generated during exploration. The selected
direction is `nowfield-v2.png`; `nowfield.png` is its byte-identical working-name
alias. The other files preserve the route that led to it and may be reused for
comparison or process material.

## Implementation captures

`captures/` contains browser renders against real VPS payloads, named by route
and viewport. They represent the issue #31 branch before deployment and are not
proof of a production release.

- `nowfield-work-desktop-1440x1000.png`
- `nowfield-work-tablet-820x1100.png`
- `nowfield-work-mobile-390x844.png`
- `nowfield-responsibility-desktop-1440x1000.png`

Conversation-workbench captures are added when that surface finishes.
